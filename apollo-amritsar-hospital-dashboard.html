Method. 94,122 encounter records were generated in Python (NumPy/pandas) with seasonal, weekday and festival effects, specialty-specific length-of-stay and tariff distributions, and payer-wise realisation factors. The dataset was aggregated into a pre-computed cube and rendered here as hand-built SVG — no charting library.

Stack. Python pandas NumPy JavaScript SVG — CSV dataset and generator script published alongside.

Reference profile: a 190-bed private multi-specialty hospital in Amritsar, Punjab. The data is simulated for portfolio and teaching use and does not represent any real institution's performance.
